# Код к главе 2.6

Таблицы — из `examples/tracking/schema.sql`: `user_acquisition` (2.1), `funnel_events` и `bot_status` (2.2), `user_activity` и `reminder_deliveries` (2.3). Новых таблиц глава не добавляет.

- `queries.sql`:
  - `quarter_card_weekly` — числа карточки квартала за прошлую календарную неделю: метрика квартала (люди на связи с недели 1, без похожих на зомби), новые на связи отдельной строкой, активированные из когорты позапрошлой недели (число и доля), два ограничителя — доля блокировок и доля зомби среди получивших напоминание;
  - `quarter_card_no_push` — то же для бота, который никогда не пишет первым: активные с недели 1 и доля блокировок среди активных.
- `north-star.test.ts` — тесты: `bun test`. Таблицы в тесте — копия из `examples/tracking/schema.sql`.

Пассивные, блокировки и зомби за неделю окончательны через неделю после её конца. Удержание активированных на неделе 4 — треугольник активированных в `examples/tracking/queries.sql` (глава 2.3).

Bun + `bun:sqlite`. Для Postgres — см. врезку в главе 0.1 и заметку о неделях в `examples/tracking/README.md`.
