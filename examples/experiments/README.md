# Код к главе 2.5

- `schema.sql` — карточка эксперимента `experiments` (гипотеза, главная метрика, правило решения, сколько людей ждём, даты) и группы `experiment_assignments` — одна строка на человека, группа не меняется. Копии таблиц `user_acquisition`, `funnel_events` и `bot_status` из `examples/tracking`.
- `experiments.ts`:
  - `assignVariant` — детерминированная группа по хешу SHA-256 от «эксперимент:telegram_id», `variantByWeek` — чередование по неделям (для того, что нельзя показать части людей: описание бота, текст профиля), `assign` — записать группу один раз, `isRunning` — идёт ли эксперимент по карточке;
  - `wilson` — интервал Уилсона для доли, `diffInterval` — интервал для разницы двух долей по Ньюкомбу (гибридный метод Уилсона); оба сверены с `statsmodels`;
  - `lehrPerArm` — правило Лера 16·p̄(1−p̄)/δ² на группу (α = 0,05, мощность 80 %), `sampleSizePerArm` — нормальное приближение с объединённой долей p̄, `sampleSizeBaselineVariance` — вариант калькулятора Эвана Миллера (разброс по базовой доле), `normInv` — квантиль нормального распределения;
  - `splitLooksBroken` — проверка разбиения (|nA − nB| > 3·√(nA + nB) при 50/50; при 2σ честное разбиение срабатывало бы в ~4,6 % экспериментов);
  - `decide` — правило решения в дату итога: `check_split`, `too_early` (меньше `minPerArm`), `ship`, `rollback`, `tie` (действует строка карточки «при ничьей»); порог большого вреда по умолчанию −15 пунктов;
  - `guardrailStop` — досрочная остановка по ограничительной метрике: не меньше 10 событий в B и весь интервал разницы выше порога;
  - `fakeDoorDecision` — правило фальшивой двери по границам Уилсона: нижняя выше 5 % — делаем, верхняя ниже 10 % — не в этом квартале, иначе ждём 80 увидевших;
  - `signTestP` — критерий знаков для чередования недель (2 из 2 — 1/4, 5 из 5 — 1/32); `variantByWeek` принимает шаблон `"AB"` или `"ABBA"`.
- `queries.sql` — главная и ограничительные метрики по группам (только «дозревшие» и только до конца эксперимента), до и после изменения по группам каналов, чередование по неделям (без дня переключения), пути тех, кто не дошёл до шага, фальшивая дверь (первое нажатие на человека), удаление по запросу.
- `experiments.test.ts` — тесты: `bun test`.

Числа в тестах — те же, что в иллюстрациях главы.

Bun + `bun:sqlite`. Для Postgres и aiogram — см. врезку в главе 0.1; идентификаторы Telegram в Postgres — `BIGINT`, `SUM(EXISTS …)` → `COUNT(*) FILTER (WHERE EXISTS …)`. В Python тот же хеш: `int.from_bytes(hashlib.sha256(f"{experiment}:{user_id}".encode()).digest()[:4], "big") % 10000`.
