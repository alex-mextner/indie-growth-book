# Код к главам 2.1 и 2.2

- `schema.sql` — таблицы: источник первого касания, коды приглашений, шаги воронки, журнал блокировок.
- `tracking.ts` — разбор параметра `/start`, запись касаний и шагов, коды приглашений, блокировки, удаление по запросу.
- `queries.sql` — перенос старых пользователей, отчёт по каналам, воронка, доля понятых сообщений, воронка по источникам.
- `tracking.test.ts` — тесты: `bun test`.

Bun + `bun:sqlite`. Для Postgres и aiogram — см. врезку в главе 0.1.
