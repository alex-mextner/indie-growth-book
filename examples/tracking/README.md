# Код к главам 2.1–2.3

- `schema.sql` — таблицы: источник первого касания, коды приглашений, шаги воронки, журнал блокировок (2.1–2.2); дни активности и журнал доставленных напоминаний — только даты, срок хранения 12 месяцев (2.3).
- `tracking.ts` — разбор параметра `/start`, запись касаний и шагов, коды приглашений, блокировки (2.1–2.2); `markActive` (только личный чат), `recordReminderDelivery` (заодно шаг воронки `first_reminder_delivered`, кроме напоминаний о чужих общих событиях), `isHumanInput`, `isBlockedError`, `ackReminder` — кнопка «знак жизни», не считается активностью (2.3); удаление по запросу из всех таблиц.
- `queries.sql` — перенос старых пользователей, отчёт по каналам, воронка, доля понятых сообщений, воронка по источникам (2.1–2.2). Раздел «(2.3)»: перенос истории активности, треугольники активного удержания (всех и активированных), пассивного и «на связи»; одно число на неделю «кроме вас»; новые / постоянные / вернувшиеся / неизвестные; похожие на зомби; путь отдельных людей; месячные когорты; удаление строк старше 12 месяцев.
- `tracking.test.ts` — тесты: `bun test`.

Bun + `bun:sqlite`. Для Postgres и aiogram — см. врезку в главе 0.1. Недели в Postgres (2.3): `date_trunc('week', first_seen_at)` вместо `date(first_seen_at, 'weekday 0', '-6 days')` (неделя там тоже с понедельника), `(day - d0) / 7` для столбцов `date` вместо разности `julianday`.
